# Mail Studio Brand Assets

Mail Studio by wolkano is an email-template editor inside Craft CMS, not a hosted email service.

- `../icon.svg`: cobalt postage-stamp icon for the Plugin Store and plugin list.
- `../icon-mask.svg`: simplified `currentColor` path for 16-24 px control panel navigation.
- `mail-studio-logo.svg`: outlined wordmark for light backgrounds.
- `mail-studio-logo-dark.svg`: outlined wordmark for dark backgrounds.

The stamp contains heading, copy, and button blocks. Primary cobalt is `#2347D9`; orange `#FF8A3D` is a non-text accent. Do not apply product branding to customers' email content or override Craft's control panel theme.

Wordmark lettering uses Schibsted Grotesk 800, with Instrument Sans for the publisher line. Both fonts are licensed under the SIL Open Font License 1.1. Their notices are included here. Lettering is converted to paths with no added letter spacing; SVG files do not embed fonts or images.
